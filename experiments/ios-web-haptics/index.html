ClassiPod haptic test

Experimental page only. It does not change music playback or wheel sounds. Test on a physical iPhone in Safari and installed PWA. A logged event is not proof of a physical haptic.

1. Tap each visible switch. 2. Drag a finger continuously across the switches. 3. Try the synthetic-click button. Note which actions actually produce a physical tap.
